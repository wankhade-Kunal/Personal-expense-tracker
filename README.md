# Personal Expense Tracker (PET)

A simple Python-based application that helps users record, manage, and track their daily expenses and income.

## Features

* **Add Transaction** – Record a new income or expense with relevant details.
* **View All Transactions** – Display all recorded transactions.
* **View Summary** – Get a summary of your income, expenses, and remaining balance.
* **Delete Transaction** – Remove a transaction when it is no longer needed.
* **Export Transactions to CSV** – Export transaction records to a CSV file for easy access and analysis.
* **Exit** – Close the application.

## Technologies Used

* Python
* File Handling
* CSV Module

## How to Run

1. Clone or download this repository.

2. Open the project folder in VS Code or your preferred code editor.

3. Run the Python file:

   ```bash
   python pet.py
   ```

4. Select an option from the menu to manage your transactions.

**Note:** Replace `main.py` with your actual Python filename if it is different.
